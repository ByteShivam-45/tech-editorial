# 📰 Tech Editorial

A responsive technology magazine website inspired by the visual style of classic tech publications. The project combines editorial typography, magazine-style layouts, article sections, and a paper-inspired visual design using **HTML5 and CSS3**.

## ✨ Features

* 📰 **Magazine-Style Layout** — Editorial-inspired page structure with multiple sections
* ✍️ **Editorial Typography** — Serif headlines combined with clean monospace text
* 📐 **Responsive Design** — Optimized for desktop, tablet, and mobile screens
* 🎨 **Paper-Inspired Theme** — Sepia tones, borders, spacing, and print-style aesthetics
* 📚 **Article Sections** — Structured technology articles with headings, metadata, and pull quotes
* 🧭 **Magazine Navigation** — Table of contents with smooth anchor navigation
* 📊 **Tech Pulse Section** — Technology-focused statistics and visual information blocks
* 🖼️ **Editorial Imagery** — Technology-themed visuals integrated into article layouts
* ⚡ **CSS Interactions** — Hover effects and visual transitions using CSS
* 📱 **Mobile-Friendly** — Responsive layouts using CSS media queries

## 📖 About the Project

**Tech Editorial** is a front-end web design project focused on creating a digital technology magazine experience.

The project explores how traditional print-editorial concepts can be translated into a modern responsive website using only **HTML and CSS**.

The design focuses on:

* Strong visual hierarchy
* Editorial typography
* Magazine-style grids
* Consistent spacing
* Responsive layouts
* Semantic HTML
* Reusable CSS styling
* CSS-based interactions
